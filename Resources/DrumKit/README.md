# Drum kit samples

Made with `Tools/DrumKitTool.cpp` from **Big Rusty Drums** by Karoryfer Samples, released under
CC0 1.0 (public domain): https://github.com/sfzinstruments/karoryfer.big-rusty-drums

Each file is `<drum>_<velocity layer>_<round robin>.flac`: close and overhead microphones mixed,
start trimmed, tail shortened with a fade, 16-bit stereo, 44.1 kHz.
