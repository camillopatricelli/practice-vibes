## For contributors
- Readers: players of any instrument, not technical. Say "your instrument" in general text; guitar examples are fine
  where they help. Plain words, short steps ("Tap X, then Y"), one idea per paragraph.
- Explain the *why* briefly where it isn't obvious (latency, monitoring, before/after FX, the plugin chain).
- Button and menu names in **bold**, exactly as shown in the app. Say "tap" and mention the computer only where it
  differs (right-click, mouse wheel, keyboard keys).
- Platform differences go in a short "On iPad / On Windows / On Mac" note, not separate chapters.
- Screenshots live in [docs/screens/](../../docs/screens/) (`en/` and `it/`, same file names), dark theme, made-up
  demo data only: no real names, no commercial songs.
- Keep it in step with the app: a feature change updates its chapter, in English and Italian.
