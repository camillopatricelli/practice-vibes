## Per chi contribuisce
- Si dà del tu, frasi brevi, parole semplici: come l'app in italiano.
- I nomi di pulsanti e menu in **grassetto**, esattamente come appaiono nell'app in italiano (Resources/Languages/it.txt).
  Le voci del pannello dei dispositivi audio (Output, Input, Active input channels, Audio buffer size, Control Panel,
  i tipi di dispositivo) restano in inglese, perché l'app le mostra in inglese.
- Le immagini sono in [docs/screens/it/](../../../docs/screens/it/), con gli stessi nomi di file della versione inglese.
- Quando cambia un capitolo inglese, si aggiorna anche questo.
