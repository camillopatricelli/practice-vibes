# Contributing

Thanks for your interest in Practice Vibes.

## Bug reports and ideas: welcome

Please use the [issues](../../issues) page, with the bug report or feature request template.

For a bug, the most useful things are:
- the diagnostic info: in the app, **Audio settings > About Practice Vibes > Copy diagnostic info**, then paste it;
- what you did, what you expected, and what happened instead;
- if you can, the end of the log file (where to find it is in the [README](README.md#problems-and-ideas)).

## Code contributions

Practice Vibes is a one-person project. Pull requests are reviewed and merged at the owner's discretion, so please
open an issue to talk about a change before you spend time on it.

Accepting outside code means the copyright of the app is shared between several people, which affects what can be
done with the project later. For that reason, small fixes are easier to accept than large features.

By submitting a contribution you agree that it is licensed under the
[GNU AGPLv3](LICENSE), the same licence as the rest of the app.

## Translations

The app's text is translatable. Translation files live in `Resources/Languages/` (`template.txt` lists every text).
If you'd like to translate the app into your language, open an issue first.
